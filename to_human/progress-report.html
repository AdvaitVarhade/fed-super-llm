🔬 RE-Privacy-Preserving Federated SUPER

Extending SUPER: Smart User-Centric Popularity Exposure Reduction (Yavru et al., IEEE Access 2026) with Federated Learning, LLM User Profiling, and Differential Privacy for fair, private, and diverse recommendations.

What We Discovered

H1 (FedSUPER): Federated SUPER perfectly matches centralized SUPER calibration. Rmse-PC = 0.0550, MRMC = 0.1506 — identical under both paradigms. The blue-print merge algorithm is provably privacy-compatible.

H3 (LLM profiles): Sentence-BERT user profiling (MiniLM-L6-v2) +23% recall and doubles catalog coverage (LTC 0.015 → 0.038). Calibration unchanged. The fusion of FL + LLM filtering is the winning combination.

Negative but revealing: DP noise (H2) reduces accuracy without helping calibration (blueprint merge already guarantees it). Adaptive DP (H5) only shows marginal benefit (+5).

Contributions

  1. FedSUPER: First privacy-preserving implementation of original SUPER algorithm — federated dual models (M_pop/M_tail) and blueprint merge. Calibration guarantees preserved exactly.
  2. LLM Brand: LLM-based user profiling (Sentence-BERT Min_LM) recovers accuracy (+23% recall) and expands catalog coverage (LTC doubled) while calibration invariant — proof that semantics and calibration are orthogonal signals.
  3. Analysis: DP noise is NOT additional in SUPER's calibration setting — the blueprint hard-quota algorithm already guarantees calibration at the per-user level, independent of backbone score uncertainty. A subtle but important construct that refines our understanding.
  4. Pareto: The combined H1+H3 configuration (LLM-FedSUPER) achieves the "best privacy + fairness + accuracy" point: recall 0.037, Rmse-PC 0.055, no raw data exposed.
